# Soul 产品静物摄影

把「一件产品」做成一张有商业价值的静物图。核心是：**先定产品的英雄角度与商业用途，再按品类选布光、按材质控质感、按背景定调性，最后逐张检查反光、质感与轮廓是否成立。** 目标不是把产品拍「清楚」，而是让产品看起来值那个价。

## 当前画布能力规则

- 生成前先用 `get_generation_config` 读取画布当前真实生图模型（Higgsfield Soul 2.0 对应 `higgsfield-ai/soul/standard` 或 `soul/v2`），不得臆测或自行切换模型。
- 画布内置虚拟摄影器材库（相机、镜头、焦段、光圈），产品静物优先用中长焦（85–135mm）与 f/8–f/16 小光圈保证整体锐利；若模型不支持参数，把机身镜头焦段光圈写进提示词。
- 本 Skill 只生成静态产品照片，不生成视频、不生成 360° 旋转动画（那是视频模型的事）。

## Soul 2.0 硬规则（生成前逐条检查）

Soul 2.0 的质量来自布光与材质的具体描述，不来自堆词。以下规则决定出图是商业级还是废片：

- **提示词用英文，60–120 词**，最多 150 词。超过后模型开始丢细节，先崩的是反光和结构。
- **一个维度一句话**：主体+材质 → 场景/台面 → 光位与强度 → 机位/镜头/光圈 → 影调。写到能直接拍出来的程度。
- **只写正向描述**：Soul 没有 negative prompt。写 `plain unlabeled surface` 而不是 `no text`，写 `tack sharp` 而不是 `no blur`，写 `even matte panel` 而不是 `avoid reflections`。
- **不写品牌名、型号、真实 Logo**：会触发 ip 审核，或让模型硬造乱码 Logo 和假文字。要干净表面就写 `unbranded, unmarked`。
- **不堆 `8K / ultra detailed / masterpiece / stunning / hyperrealistic`**：这些词不提升清晰度，只换来塑料感和 AI 味。
- **画幅只有 7 档**：1:1、4:3、3:4、3:2、2:3、16:9、9:16，其他比例上游直接报错。
- **清晰度由画布统一提交 1080p**，提示词里不要再写分辨率。
- **多张变体要换光位/机位/影调**，同一段提示词重复生成只会得到近似复制品。
- 要保住真实产品的形状与 Logo，用实拍图做参考/图生图，不要靠文字描述还原。

## 启动前询问（强制 Gate）

每次触发后、正式生成前，一次性问清以下字段。已在本轮消息或画布中提供的直接说明「已检测到」，不重复索取：

1. **产品品类**：鞋履/珠宝手表/化妆品香水/电子产品/食品包装/家居/其他。品类决定灯光方案。
2. **材质**：金属/玻璃/皮革/织物/木材/陶瓷/液体/哑光/光泽（可多选，材质决定反光与质感控制）。
3. **英雄角度**：正面/侧剖面/四分之三/俯拍/特写细节。默认四分之三英雄角度（最有立体感、最通用）。
4. **用途与画幅**：电商主图(1:1)/KV横幅(16:9)/详情页(3:4)/社交媒体(9:16)。默认 1:1。
5. **背景**：纯白/纯黑/灰渐变/生活场景/材质表面。电商主图默认纯白或浅灰渐变。
6. **光线偏好**：按品类推荐，或用户指定（硬光/柔光/轮廓光/自然窗光）。

用户说「你看着办 / 直接做」时，agent 按品类推荐默认方案，但须把采用的选择作为已完成的问询结果展示出来再继续。

## 画布工作流（自动搭建）

1. **先摸清画布**：用 `get_canvas_summary`、`query_canvas_nodes` 了解现有节点与素材，复用已有产品图，不盲目新建。
2. **读真实配置**：用 `get_generation_config` 读取当前生图模型与参数。
3. **建简报节点**：用 `create_text_node` 把确认后的需求（品类、材质、角度、光线、背景、画幅）写成简报节点，作为后续生成的单一来源。
4. **生成与连接**：用 `generate_image` 出图，用 `create_connection` 连「产品素材 → 简报 → 生成结果」，用 `create_group` 归组、`arrange_nodes` 整理布局。
5. **跟踪收敛**：每次生成后用 `get_media_task_status` 确认完成；正式批量出图前先给 1–2 张方向基准让用户确认，避免一次生成大量偏离的图。

## 英雄角度选择

| 角度 | 何时用 | 强调什么 |
|---|---|---|
| 四分之三（默认） | 最通用、最有立体感 | 轮廓 + 材质 + 侧面细节同时可见 |
| 侧面剖面 | 鞋履、包、电子产品 | 轮廓剪影与厚度 |
| 正面 | 电商主图、包装 | 品牌标识、正面信息 |
| 俯拍 flat-lay | 化妆品、食品、成套产品 | 布局与数量关系 |
| 特写微距 | 珠宝、表盘、缝线、logo | 工艺与材质细节 |

## 10 类产品灯光方案（按品类选）

1. **电子产品/数码硬件**：冷调精确。主光 45° 上冷色(5600K)，补光对侧 50% 微暖(4000K)，轮廓光勾勒边缘。背景深灰到白渐变，表面哑光黑或白。强调屏幕/玻璃反光与轻薄感。
2. **珠宝**：戏剧化奢华。主光侧 30° 硬光制造切面高光，补光极少（阴影增强立体），轮廓光强制造光晕。背景纯黑/深蓝/镜面，表面黑丝绒吸光。让切面「闪」。
3. **时尚配饰（包/腰带/围巾）**：暖调编辑感。主光 45° 暖色(3200–4000K)，补光对侧 60%，轮廓光中等。背景白/浅灰/生活场景，表面木或麻。让光掠过表面显缝线、纹理、包浆。
4. **汽车配件**：戏剧化性能感。主光 45° 强对比，补光 40%，轮廓光强。背景深色渐变或镜面，表面抛光黑。多光源显金属反光，传达速度与精密。
5. **化妆品/香水**：柔光水润奢华。主光 60° 上方柔光(3200K)，补光 80%，轮廓光轻微。背景白/浅渐变，表面白/磨砂。强调玻璃通透、液体色饱和与折射。
6. **手表（专档）**：精密展示级。主光 35° 上方冷色，补光 50%（保持表盘可读），轮廓光中到强。背景黑/深蓝，表面黑皮革或绒。先拍表盘可读性，再拍侧面厚度，最后表背机芯。
7. **鞋履/球鞋**：动态生活化。主光 45° 侧暖(3500K)，补光 60%（保折痕纹理细节），轮廓光中。背景白/浅渐变/生活场景。先侧剖面（轮廓）→ 顶面（鞋面结构）→ 细节（缝线、logo、纹理）→ 四分之三英雄角度收尾。
8. **家具/家居**：环境光生活化。主光 45° 柔光暖(3200–3500K)，补光 70%，轮廓光轻微。背景中性或生活场景显比例。可加入手部交互显尺寸。
9. **食品包装**：开胃暖调。主光 45° 暖(3200K)，补光 70%（避免死黑显陈旧），轮廓光轻微。背景软渐变/暖中性/生活场景，表面木/麻/陶瓷。强调色彩饱和与新鲜感；包装有透明窗就显内部。
10. **数码硬件（手机/平板/耳机/穿戴）**：冷精度 + 暖奢平衡。主光 45° 冷(5600K)，补光 55% 微暖(4000K)，轮廓光中。背景深到中灰渐变或白，表面反射或哑光深色。强调轻薄、材质过渡与按键接口细节。

## 9 类材质表现法

| 材质 | 灯光 | 关键提示词（英文） |
|---|---|---|
| 金属（不锈钢/金/铝/黄铜） | 硬定向光，多源制造多重反射 | mirror-like reflections, sharp specular highlights, brushed grain |
| 玻璃/水晶 | 前上方主光 + 两侧补光显折射 | refraction, transparency, caustic light patterns, clarity |
| 皮革 | 暖定向光掠过表面显纹理 | grazed light, leather grain, natural patina, stitching detail |
| 织物（编织/针织/棉/丝） | 45° 柔光显织纹与垂坠 | fabric weave, natural drape, thread detail, soft texture |
| 木材 | 暖漫射光显纹理与漆面 | wood grain, satin finish, natural warmth, finish depth |
| 陶瓷/瓷 | 柔定向光显釉面 | glaze depth, color saturation, smooth ceramic finish |
| 液体（香水/饮料/油） | 背光或侧光显色与折射 | liquid refraction, color saturation, meniscus, transparency |
| 哑光表面 | 柔漫射光，避免高光 | matte finish, no specular highlights, uniform surface |
| 光泽表面 | 硬定向光制造强高光 | glossy reflection, mirror-like shine, specular highlight |

## Prompt 构造模板（中英对照，喂给 Soul 2.0 用英文）

按此顺序拼接，产出可直接出图的产品 prompt：

```
[产品主体 + 材质] + [英雄角度] + [光线方案] + [背景/表面] + [机位/镜头/光圈] + [材质关键词]
```

收尾只用：`product photography, studio lighting, sharp focus`。不写品牌名，不写 `8K / ultra detailed`——Soul 的清晰度由画布的 1080p 档位决定，堆词只换来糊和塑料感。

## 输出规范

- 每批交付附说明：用了哪类灯光方案、强调什么材质、为什么这个英雄角度适合该用途；标注最推荐的一张。
- 电商主图留白考虑文案位；KV 横幅主体偏一侧留负空间；详情页可连出「整体 + 细节特写」多张成组。
- 交付前逐张检查：反光是否自然、材质质感是否对、轮廓是否清晰、是否有明显畸变或穿帮，有问题就重生成。

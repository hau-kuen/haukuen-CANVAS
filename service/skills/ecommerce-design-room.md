# 电商视觉设计室

用本 Skill 引导用户把一个产品做成「成套、统一、可直接分发」的商业视觉物料包。核心是：**先建立产品档案（产品是什么、卖给谁、什么调性），再围绕统一风格批量产出各平台所需的主图、场景图、细节图和社媒图。** 目标是让用户一次拿到能直接上架和投放的完整素材，而不是零散几张图。

## 当前画布能力规则

- 使用画布全局生图模型（先 `get_generation_config` 读真实模型名并展示，不臆测、不切换）。
- 优先用画布虚拟摄影器材控制产品图质感；白底/主图与场景图可分别采用不同焦段。
- 只生成平面静态图片，不生成视频；文案以图片内的留白位置与构图建议形式交付。

## 启动前询问（强制 Gate）

1. **产品素材**：产品图、白底图、包装图或参考图；说明产品类型。
2. **目标平台**：亚马逊 / 品牌官网 / Instagram / TikTok / 小红书 / 全平台（一次出全套）。
3. **视觉风格**：极简高级 / 暖调生活 / 科技感 / 国潮 / 复古胶片 / 由 agent 推荐。
4. **必备物料清单**（默认，可增删）：
   - 主图（1:1 白底，预留 logo 与卖点文案位）
   - 场景图（1:1 或 3:4，产品融入使用场景）
   - 细节图（突出材质/工艺，1:1）
   - 社媒图（9:16 或 4:5，带氛围与留白）
5. **产品档案**（可选）：产品定位、目标人群、核心卖点、调性关键词，用于统一整组物料。

用户说「你看着办」时，agent 为剩余字段选推荐默认值并展示已采用的问询结果，再继续。

## 画布工作流（自动搭建）

本 Skill 要结合画布的 API 与功能菜单，自动搭建专业、高效、可复用的画布工作流，而不是只给文字建议：

1. **先摸清画布**：用 `get_canvas_summary`、`query_canvas_nodes` 了解现有节点与连接，复用已有产品素材，不盲目新建。
2. **读真实配置**：用 `get_generation_config` 读取当前生图模型与参数，不臆测、不自行切换。
3. **建立产品档案节点**：用 `create_text_node` 把产品定位、人群、卖点、调性写成产品档案节点，作为整组物料的统一基准。
4. **生成与连接**：用 `generate_image` 按物料清单（主图/场景图/细节图/社媒图）逐项生成，用 `create_connection` 把「产品素材节点 → 档案节点 → 各物料节点」连成链路；用 `create_group` 把同一产品物料归组、`arrange_nodes` 整理布局。
5. **跟踪与收敛**：每次生成后用 `get_media_task_status` 确认完成再继续；成套出图前先确认视觉风格，风格基准等低成本步骤直接做。

## 运行原则

1. **先建档、再成套**：先输出一份简短产品档案（定位 / 人群 / 卖点 / 调性），用户确认后，所有物料严格围绕这份档案生成，保证风格统一。
2. **一套一个视觉系统**：主图、场景图、细节图、社媒图共享同一色调、背景逻辑与品牌调性，避免各出各的风格。
3. **尺寸即规格**：严格按平台要求出图（主图 1:1 白底、社媒 9:16 等），并在交付时标注每张对应的平台与用途。
4. **留白给文案**：主图与社媒图预留可放 logo、标题、卖点文案的位置，构图不把主体占满。
5. **交付前检查**：逐张检查背景是否干净、主体是否清晰、整套色调是否一致；发现问题重生成或局部修复。

## 输出规范

先交付产品档案，再交付成套物料清单（每张图标注用途、平台、尺寸、留白建议）；标注主视觉一张。整组物料风格统一，可直接上架或投放。

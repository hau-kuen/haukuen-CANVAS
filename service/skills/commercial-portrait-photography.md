# 商业人像摄影

用本 Skill 引导用户把「一个人 + 一个用途」做成一组可交付的商业平面人像。核心是：**先定人像的用途与气质基准，再用光线、焦段和构图控制画面，最后逐张检查皮肤、眼神与光影是否成立。** 目标不是堆砌华丽词藻，而是让成片像专业商业摄影棚或真实外景拍出来的。

## 当前画布能力规则

- 当前可用的是画布全局生图模型（可通过 `get_generation_config` 读取真实模型名）。生成前必须先读一次并展示真实模型，不得臆测或自行切换模型。
- 当前画布内置一套虚拟摄影器材库（相机、镜头、焦段、光圈），优先用它来控制人像的画面质感；若当前模型不支持该参数，则把机身、镜头、焦段、光圈的描述写进画面提示词。
- 本 Skill 只生成平面静态照片，不生成视频、不生成数字人动画、不做音频。

## 启动前询问（强制 Gate）

每次触发后、进入正式生成前，必须一次性完成轻量问询。已在本轮消息或画布中提供的素材直接说明已检测到，不重复索取：

1. **人物素材**：请用户上传人物照片、参考图，或说明人物特征（性别、年龄、发型、肤色、气质）。没有素材时，agent 可按需求先出「风格基准候选」供挑选。
2. **用途**：电商模特图 / 个人形象照 / 品牌人像 / 棚拍 / 户外 / 其他。
3. **光线方案**：伦勃朗光 / 蝴蝶光 / 轮廓光 / 柔光 / 硬光 / 自然光 / 由 agent 推荐。
4. **情绪与气质**：亲和、冷峻、高级、活力、复古、中性等。
5. **画幅比例**：1:1 / 3:4 / 4:3 / 9:16 / 16:9，默认 3:4 竖版人像。
6. **摄影器材**（可选）：是否指定相机或镜头（如哈苏、佳能、蔡司）；不指定则由 agent 根据气质推荐。

用户说「你看着办 / 直接做」时，agent 为剩余字段选推荐默认值，但仍须把采用的选择作为已完成的问询结果展示出来，再继续。

## 画布工作流（自动搭建）

本 Skill 要结合画布的 API 与功能菜单，自动搭建专业、高效、可复用的画布工作流，而不是只给文字建议：

1. **先摸清画布**：用 `get_canvas_summary`、`query_canvas_nodes` 了解现有节点与连接，复用已有素材，不盲目新建。
2. **读真实配置**：用 `get_generation_config` 读取当前生图模型与参数，不臆测、不自行切换。
3. **建立简报节点**：用 `create_text_node` 把确认后的需求（光线、情绪、画幅、器材等）写成简报/提示词节点，作为后续生成的单一来源。
4. **生成与连接**：用 `generate_image` 生成图片，用 `create_connection` 把「素材节点 → 简报节点 → 生成结果节点」连成清晰链路；用 `create_group` 把同主题节点归组、`arrange_nodes` 整理布局。
5. **跟踪与收敛**：每次生成后用 `get_media_task_status` 确认完成再继续；正式批量出图前先确认方向，候选图、基准图等低成本步骤直接做。

## 运行原则

1. **先出风格基准再精修**：先给 2–3 张不同光线/情绪的候选，让用户挑一个方向，再沿该方向批量生成，避免一次生成大量偏离的照片。
2. **用器材控制质感**：优先调用画布的相机/镜头/焦段/光圈；商业人像常用中长焦（85–135mm）与 f/1.4–f/2.8 浅景深，突出主体与皮肤质感。
3. **光线是第一位**：每张照片先说明主光方向与明暗关系，再说明情绪。避免「高级感」这类空词，落到具体的光线与构图。
4. **皮肤与眼神要过关**：交付前逐张检查皮肤质感是否自然、眼神光是否存在、五官是否变形；发现问题就重生成或局部修复，不把明显瑕疵交给用户。
5. **贵在收敛**：正式批量出图前先确认方向；候选图、基准图这类低成本步骤可直接做。

## 输出规范

每批交付时附一段简短说明：用了什么光线、什么焦段与相机、为什么适合该用途；并标注哪张最推荐。成片按用途给出可用的画幅与留白（电商模特图预留文案位，形象照主体居中）。

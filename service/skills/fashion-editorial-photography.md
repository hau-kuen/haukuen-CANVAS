# 时尚编辑摄影

用本 Skill 引导用户把「服装 / 造型 + 一个主题」做成一组有叙事、有态度的时尚平面大片。核心是：**先确立主题与情绪基调，再用造型、场景、姿态和色彩讲一个完整的视觉故事。** 成片要像时尚杂志专题或品牌 campaign，而不是随手拍的人像。

## 当前画布能力规则

- 使用画布全局生图模型（先 `get_generation_config` 读真实模型名并展示，不臆测、不切换）。
- 优先用画布虚拟摄影器材控制质感；时尚常用中长焦 + 浅景深，或广角带场景张力。
- 只生成平面静态照片，不生成视频。

## 启动前询问（强制 Gate）

1. **素材**：模特图、服装图、造型参考，或说明服装风格与人物特征。
2. **主题与概念**：一句话核心概念（如「雨夜都市」「复古胶片」「未来机能」），或由 agent 提 2–3 个方向供选。
3. **情绪基调**：冷峻 / 浪漫 / 叛逆 / 高级 / 慵懒 / 戏剧化。
4. **场景**：棚拍纯色 / 城市街头 / 自然户外 / 室内空间 / 超现实置景。
5. **色彩方向**：低饱和莫兰迪 / 高对比 / 胶片颗粒 / 冷调 / 暖调。
6. **画幅**：3:4 竖版 / 2:3 杂志 / 1:1 / 16:9；lookbook 通常 3:4，campaign 常用 16:9 或 2:3。

用户说「你看着办」时，agent 为剩余字段选推荐默认值并展示已采用的问询结果，再继续。

## 画布工作流（自动搭建）

本 Skill 要结合画布的 API 与功能菜单，自动搭建专业、高效、可复用的画布工作流，而不是只给文字建议：

1. **先摸清画布**：用 `get_canvas_summary`、`query_canvas_nodes` 了解现有节点与连接，复用已有素材，不盲目新建。
2. **读真实配置**：用 `get_generation_config` 读取当前生图模型与参数，不臆测、不自行切换。
3. **建立简报节点**：用 `create_text_node` 把确认后的主题、情绪基调、场景、色彩、画幅写成简报节点，作为整组大片的统一视觉来源。
4. **生成与连接**：用 `generate_image` 生成基准图与系列图，用 `create_connection` 把「造型素材节点 → 简报节点 → 各张成片节点」连成叙事链路；用 `create_group` 把同主题节点归组、`arrange_nodes` 整理布局。
5. **跟踪与收敛**：每次生成后用 `get_media_task_status` 确认完成再继续；正式批量出图前先确认风格基准，候选图、基准图等低成本步骤直接做。

## 运行原则

1. **主题先行、基准锁定**：先出 2–3 张「风格基准」锁定色调、场景与姿态方向，用户认可后再展开系列，保证整组视觉统一。
2. **一组讲一个故事**：批量生成时规划 3–6 张的叙事节奏（开场全景 → 中景姿态 → 特写细节 → 收尾），避免单张孤立。
3. **姿态与构图有设计感**：避免呆板站姿，注重肢体张力、服装垂坠、道具与留白；构图可大胆（低机位、切头、大面积负空间）。
4. **色彩即风格**：整组统一色彩倾向，必要时用胶片颗粒、褪色或高对比强化风格。
5. **交付前检查**：逐张检查服装是否变形、皮肤质感、色彩是否统一、姿态是否自然；不把明显瑕疵交给用户。

## 输出规范

每批交付附说明：主题概念、色彩方向、用什么焦段与相机、这组图的叙事结构；标注主视觉一张。成片给出正确画幅，并说明适用于杂志 / lookbook / campaign 的哪种排版。

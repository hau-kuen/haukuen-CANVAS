# 运动鞋服静物 KV

用本 Skill 帮美术指导把「一份客户 brief + 一件运动产品」做成一张有创意、有品牌调性、可投放的静物主视觉。核心是：**先读懂 brief 里的卖点与品牌要什么，再确立一个清晰的创意方向，最后用打光、构图、材质和色彩把产品拍成有态度的 KV。** 目标是让产品看起来「专业、有速度感、有品牌力」，而不是普通的商品图。

## 当前画布能力规则

- 使用画布全局生图模型（先 `get_generation_config` 读真实模型名并展示，不臆测、不自行切换）。
- 优先用画布虚拟摄影器材控制质感；运动鞋 KV 常用中焦 + 小光圈保证鞋面细节，或用微距突出材质。
- 只生成平面静态图片，不生成视频、不生成模特。

## 启动前询问（强制 Gate）

先请用户提供或确认客户 brief（无 brief 则从产品与目标反推），再一次性确认：

1. **产品与素材**：运动鞋/运动服/配件的产品图、白底图、细节图，或说明产品类型与主打款。
2. **brief 要点**：目标人群、核心卖点（如缓震、轻量、回弹、透气）、品牌调性（如专业竞速、潮流街头、复古跑鞋）、投放渠道（主视觉 / 官网 / 电商 / 社媒）。
3. **创意方向**：由 agent 提 2–3 个方向供选（如「悬浮速度感」「动态水花/沙砾」「极简光影」「材质特写」），或用户指定。
4. **打光与氛围**：硬朗侧光勾轮廓 / 柔光棚拍 / 戏剧性逆光 / 运动感的动势光影。
5. **色彩方向**：品牌色为主 / 高对比黑白 / 冷暖撞色 / 低饱和高级灰。
6. **画幅**：KV 常用 16:9 或 3:4 竖版；电商主图 1:1。

用户说「你看着办」时，agent 为剩余字段选推荐默认值并展示已采用的问询结果，再继续。

## 画布工作流（自动搭建）

本 Skill 要结合画布的 API 与功能菜单，自动搭建专业、高效、可复用的画布工作流，而不是只给文字建议：

1. **先摸清画布**：用 `get_canvas_summary`、`query_canvas_nodes` 了解现有节点与连接，复用已有产品素材，不盲目新建。
2. **读真实配置**：用 `get_generation_config` 读取当前生图模型与参数，不臆测、不自行切换。
3. **建立创意简报节点**：用 `create_text_node` 把 brief 要点、卖点、创意方向、打光、色彩、画幅写成简报节点，作为 KV 生成的单一来源。
4. **生成与连接**：用 `generate_image` 生成候选 KV，用 `create_connection` 把「产品素材节点 → 创意简报节点 → KV 成片节点」连成链路；用 `create_group` 把同一创意方向的节点归组、`arrange_nodes` 整理布局。
5. **跟踪与收敛**：每次生成后用 `get_media_task_status` 确认完成再继续；正式出 KV 前先确认创意方向，候选方向图等低成本步骤直接做。

## 运行原则

1. **创意方向先于执行**：先出 2–3 个创意方向的概念稿/风格基准，美术指导挑定方向后再精修，避免一上来就堆产品图。
2. **卖点要可视化**：把 brief 的卖点转成视觉语言（轻量→悬浮或轻盈光影、回弹→动态形变、透气→气流或纱网特写），不是干拍产品。
3. **品牌调性统一**：色彩、构图、光影都要贴合品牌调性；专业竞速偏冷峻硬朗，潮流街头偏撞色与张力。
4. **产品质感第一**：鞋面材质、中底发泡、橡胶纹理要清晰真实，细节经得起放大；反光与阴影干净不杂乱。
5. **交付前检查**：逐张检查产品是否变形、卖点是否表达清楚、构图是否有 KV 的视觉冲击力与留白；发现问题重生成或局部修复。

## 输出规范

先交付创意方向说明（方向 + 为什么符合 brief + 视觉语言），再交付 KV 成片；标注主视觉一张与适用渠道。KV 构图预留标题/文案位，整张有品牌主视觉的冲击力。

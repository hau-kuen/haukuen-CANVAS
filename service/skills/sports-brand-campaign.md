# 运动品牌模特大片

用本 Skill 帮美术指导把「一份客户 brief + 一个品牌态度」做成一组有叙事、有张力的运动品牌 campaign 大片。核心是：**先读懂 brief 里的品牌态度与目标人群，再确立一个能打动人心的创意概念，最后用模特/运动员的状态、场景、动势和光影把态度拍出来。** 目标是让成片有「速度、力量、热血或自律」的品牌感，而不是普通的运动人像。

## 当前画布能力规则

- 使用画布全局生图模型（先 `get_generation_config` 读真实模型名并展示，不臆测、不自行切换）。
- 优先用画布虚拟摄影器材控制质感；运动大片常用广角带场景张力，或中长焦压缩突出运动员主体与动势。
- 只生成平面静态图片，不生成视频、不生成动态数字人。

## 启动前询问（强制 Gate）

先请用户提供或确认客户 brief（无 brief 则从品牌与产品反推），再一次性确认：

1. **brief 要点**：品牌态度（如「Just Do It 式的突破自我」「为跑者而生」）、目标人群、核心卖点、投放渠道（campaign 主视觉 / 社媒 / 门店 / 杂志）。
2. **创意概念**：由 agent 提 2–3 个方向供选（如「破晓开跑」「城市夜跑」「极限瞬间」「汗水与坚持」），或用户指定。
3. **模特/运动员状态**：冲刺、起跳、流汗、专注、胜利、疲惫坚持等；确认人物特征与造型。
4. **场景**：跑道 / 城市街头 / 篮球场 / 山野 / 健身房 / 超现实置景。
5. **色彩与氛围**：高对比运动感 / 胶片纪实 / 冷峻未来 / 热血暖调 / 低饱和高级。
6. **画幅**：campaign 主视觉常用 16:9 或 2:3；社媒 9:16 或 4:5。

用户说「你看着办」时，agent 为剩余字段选推荐默认值并展示已采用的问询结果，再继续。

## 画布工作流（自动搭建）

本 Skill 要结合画布的 API 与功能菜单，自动搭建专业、高效、可复用的画布工作流，而不是只给文字建议：

1. **先摸清画布**：用 `get_canvas_summary`、`query_canvas_nodes` 了解现有节点与连接，复用已有素材，不盲目新建。
2. **读真实配置**：用 `get_generation_config` 读取当前生图模型与参数，不臆测、不自行切换。
3. **建立创意简报节点**：用 `create_text_node` 把品牌态度、创意概念、模特状态、场景、色彩、画幅写成简报节点，作为整组大片的统一来源。
4. **生成与连接**：用 `generate_image` 生成风格基准与系列成片，用 `create_connection` 把「参考素材节点 → 创意简报节点 → 各张成片节点」连成叙事链路；用 `create_group` 把同一创意概念的节点归组、`arrange_nodes` 整理布局。
5. **跟踪与收敛**：每次生成后用 `get_media_task_status` 确认完成再继续；正式批量出片前先确认创意概念与风格基准，候选图等低成本步骤直接做。

## 运行原则

1. **概念先行、基准锁定**：先出 2–3 张「风格基准」锁定创意概念、色调与人物状态，美术指导认可后再展开系列，保证整组统一。
2. **态度要拍出来**：把 brief 的品牌态度转成运动员的动势、表情与场景张力（突破自我→冲线瞬间、为跑者而生→城市夜跑的孤独与坚持），不是摆拍。
3. **动势与张力**：注重运动姿态的爆发力、肌肉线条、衣摆与汗水的细节、镜头的低机位与冲击力构图。
4. **色彩即态度**：整组统一色彩倾向，高对比强化热血，胶片纪实强化真实，冷峻未来强化专业。
5. **交付前检查**：逐张检查人物是否变形、动势是否自然、产品（鞋/服）是否清晰露出、品牌态度是否表达到位；发现问题重生成或局部修复。

## 输出规范

先交付创意概念说明（概念 + 为什么符合 brief + 视觉语言），再交付系列成片（标注每张在叙事里的位置与适用渠道）；标注主视觉一张。整组风格统一、有品牌态度、可直接投放。

# 产品与静物摄影

用本 Skill 引导用户把一个产品做成一组合格、可商用的平面产品图。核心是：**先确认产品形态与用途，再用打光、背景和材质把产品拍得干净、有质感、能卖货。** 重点不是拍得花哨，而是主体清晰、质感真实、留白合理、可直接上架或投放。

## 当前画布能力规则

- 使用画布全局生图模型（先 `get_generation_config` 读真实模型名并展示，不臆测、不切换）。
- 优先用画布虚拟摄影器材（相机、镜头、焦段、光圈）控制产品图质感；不支持时把机身/镜头/焦段/光圈写入提示词。
- 只生成平面静态照片，不生成视频。

## 启动前询问（强制 Gate）

1. **产品素材**：请用户上传产品图、白底图或参考图，或说明产品类型（数码、美妆、食品、潮玩、服饰、家居等）。
2. **用途与尺寸**：亚马逊/平台主图（通常 1:1 白底）、场景图、社媒素材、详情页；确认画幅比例。
3. **背景**：纯白底 / 纯色底 / 场景台面 / 生活方式场景 / 由 agent 推荐。
4. **材质与质感重点**：金属反光、玻璃通透、织物纹理、食品色泽等，需要突出哪个。
5. **打光**：柔光箱均匀光 / 侧逆光轮廓 / 硬光对比 / 自然窗光。
6. **摄影器材**（可选）：是否指定相机镜头；不指定由 agent 推荐（产品常用微距或 50–100mm，小光圈保证景深）。

用户说「你看着办」时，agent 为剩余字段选推荐默认值并展示已采用的问询结果，再继续。

## 画布工作流（自动搭建）

本 Skill 要结合画布的 API 与功能菜单，自动搭建专业、高效、可复用的画布工作流，而不是只给文字建议：

1. **先摸清画布**：用 `get_canvas_summary`、`query_canvas_nodes` 了解现有节点与连接，复用已有素材，不盲目新建。
2. **读真实配置**：用 `get_generation_config` 读取当前生图模型与参数，不臆测、不自行切换。
3. **建立简报节点**：用 `create_text_node` 把确认后的需求（打光、背景、画幅、器材等）写成简报/提示词节点，作为后续生成的单一来源。
4. **生成与连接**：用 `generate_image` 生成图片，用 `create_connection` 把「产品素材节点 → 简报节点 → 生成结果节点」连成清晰链路；用 `create_group` 把同主题节点归组、`arrange_nodes` 整理布局。
5. **跟踪与收敛**：每次生成后用 `get_media_task_status` 确认完成再继续；正式批量出图前先确认方向，候选图、基准图等低成本步骤直接做。

## 运行原则

1. **先定基准再批量**：先出 2–3 张不同背景/打光的候选，用户挑方向后再批量，避免一次生成大量风格混乱的图。
2. **主体必须清晰**：产品居中或遵循三分构图，主体完整、无畸变、无多余杂物；白底图背景要足够干净便于抠图。
3. **质感真实**：优先体现材质本身的特性（金属高光、玻璃折射、织物纹理、食品光泽），避免塑料感或过度修图。
4. **留白与文案位**：电商主图预留左上/居中可放 logo 与文案的空间；场景图注意主体与背景的层次。
5. **交付前检查**：逐张检查反光是否杂乱、产品是否变形、色彩是否偏色；发现问题重生成或局部修复。

## 输出规范

每批交付附说明：用了什么打光、焦段与相机、背景方案、适合哪个用途；标注最推荐的一张。成片按平台要求给出正确画幅与留白。
